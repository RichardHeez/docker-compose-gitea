    Slides & templates

    Design your own slides with text boxes, images and shapes. A template has a “Main text” box: pick it for an output under Outputs → Template and every verse and song on that screen uses your layout.

    Record & stream

    4K needs about 25 Mbps of upload speed and a strong computer (F8 uses the graphics card’s video encoder when it has one). YouTube accepts 4K; Facebook streams up to 1080p.

          Stage & logo

          Hardware triggers (Stream Deck, Companion, MIDI)

          Any button box or app that can send a web request can run F8 — e.g. a Stream Deck with Bitfocus Companion (“Generic HTTP” → POST). Add ?pin=… if you set a control PIN.

          Trigger addresses

          MIDI

          Connect a MIDI pad or keyboard, turn on MIDI, then press “Learn” and hit a key.

          Lighting (DMX over Art-Net)

          Send lighting levels to an Art-Net node or lighting desk from macros or triggers.

          Long passages

          Import songs from other software

          Or paste songs copied from any program or website

          Copy the lyrics out of MediaShout, Proclaim, Planning Center, a website or a document and paste them here — as many songs as you like. Start each song with # Song title (or put a line of --- between songs). Optional lines under the title: Artist:, CCLI:, Copyright:.

          What can I import?
          • EasyWorship 2009: Songs.DB and Songs.MB from its Data folder · SongShow Plus: .sbsong files
          • EasyWorship 6/7: Songs.db and SongWords.db from Documents\Softouch\EasyWorship\Default\Databases\Data (or zip that folder)
          • ProPresenter 4/5/6: .pro4 .pro5 .pro6 · ProPresenter 7: .pro or .probundle (text only, sections re-detected)
          • OpenLP: OpenLyrics export (.xml) or its songs.sqlite · FreeWorship, Worship Extreme, VideoPsalm…: OpenLyrics export
          • OpenSong song files · CCLI SongSelect: .usr or .txt downloads · ChordPro chord charts (.cho .chordpro, chords removed)
          • PowerPoint / Google Slides / Keynote (export as .pptx) · Word (.docx) · plain .txt
          • Anything else (MediaShout, Proclaim, Planning Center…): paste the lyrics above, or use the free program OpenLP as a bridge — import your songs into OpenLP, export them as OpenLyrics, then import that file here.
